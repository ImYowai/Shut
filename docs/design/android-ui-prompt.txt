Use case: ui-mockup
Asset type: high fidelity Android app UI design sample for an existing product named Shut.
Primary request: one carefully designed presentation image showing three straight-on Android phone screens side by side on a quiet dark background. Shut is a Windows remote control and scheduled shutdown utility. The app lets the owner scan a PC's connection QR, see the remote desktop, type Japanese text, scroll naturally, and monitor shutdown timers.
Existing style: dark navy surfaces, soft translucent cards, lavender accent, mint connection indicator. Improve legibility and spacing with understated modern Android typography and 48dp touch targets. No excessive glow or decorative neon.
Screen 1: connection landing, title "Shut", subtitle "PCとつながる", an elegant central QR scanner frame with a sample nonfunctional QR motif, primary action "QRコードを読み取る", secondary "URLを入力", small recent device card "DESKTOP-PC".
Screen 2: remote control, title "リモート", mint status "接続中", wide realistic Windows desktop preview with a text editor and ordinary window chrome (no brands), toolbar "スクロール" and "ドラッグ", a two-line Japanese text composer reading "日本語の入力テスト", primary button "送信", large Enter / Tab / Esc / arrow key controls, bottom navigation "接続", "リモート", "設定". Make remote preview dominant.
Screen 3: timer/settings, title "設定", device connection status card, clear card "シャットダウン予約", value "60分後", graceful safety card "猶予 60秒", prominent lavender "監視開始" button and separated muted red shutdown action.
Composition: three full screen app mockups with restrained thin phone frames, ample gutters, aligned baselines, high clarity, landscape 3:2 design board. Japanese text should be accurate, readable and concise. Show realistic usable UI, no hands, no extra marketing slogans. Small caption "UI CONCEPT" at bottom to mark proposed design. This is a design concept, not a screenshot of a shipped app.
